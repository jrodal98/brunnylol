About Brunnylol

Brunnylol is a self-hosted take on Meta's "bunnylol" — a smart-bookmark service that turns short aliases into powerful shortcuts. Type an alias (optionally followed by a query) into the search box, and Brunnylol sends you straight where you meant to go: g rust programming runs a Google search, gh jrodal98/brunnylol opens a GitHub repo, yt lo-fi beats searches YouTube.

What it does

  • Built-in bookmarks — a starter set of aliases for common sites, loaded from commands.yml. See them all on the Help page.
  • Personal bookmarks — create your own aliases, override built-ins, and set a default alias for unknown searches.
  • Templates — bookmarks can take variables ({query}, {user}, your own named variables, maps and options) and nest sub-commands under one alias.
  • Create with AI — describe the bookmark you want and an AI model proposes one for you to accept, edit, or refine with follow-ups.
  • Import & export — move bookmark sets in and out as YAML or JSON.

How it works

Every search goes through /search?q=<alias> <query>. The first word is the alias; the rest becomes the query, which is dropped into the bookmark's URL template. Point your browser's custom search engine at that URL and Brunnylol becomes your address-bar command line.

Brunnylol is open source (a fork/continuation of an earlier bunnylol implementation) — the code lives at github.com/jrodal98/brunnylol.
